# Daleel | دليل

**Smart government inquiry assistant designed to make organizational data easier to search, understand, and access.**

🔗 **Live Demo:** https://daleel-chi.vercel.app/

## Overview

**Daleel (دليل)** is a smart inquiry assistant designed to help government employees access organizational information through a simple conversational interface.

Instead of manually searching across multiple data sources, users can ask questions in natural language and receive relevant answers based on the information available within the system.

The platform also supports managing data sources, allowing authorized users to expand and maintain the knowledge available to the assistant.

## Key Features

- **Natural Language Queries** — Allows users to search organizational information by asking questions naturally.
- **Smart Information Retrieval** — Retrieves relevant information from available organizational data sources.
- **Arabic-Friendly Experience** — Designed around Arabic government and organizational use cases.
- **Data Source Management** — Authorized users can add and manage the sources used by the system.
- **Centralized Access** — Provides a single interface for accessing information distributed across different sources.
- **Role-Based Experience** — Supports different interfaces and access levels based on user roles.
- **Administrative Dashboard** — Provides tools for managing the system and its information sources.

## How It Works

```text
User Question
     ↓
Smart Inquiry Interface
     ↓
Search Available Data Sources
     ↓
Retrieve Relevant Information
     ↓
Present Answer to User
````

## Main Interfaces

### Employee Interface

Employees can use the smart assistant to:

* Ask questions in natural language
* Search available organizational information
* Access relevant answers through a unified interface

### Administration Interface

Authorized users can:

* Manage data sources
* Add new information sources
* Control access based on user roles
* Maintain the information available to the assistant

## Prototype Scope

The current version demonstrates the concept of a centralized smart inquiry assistant for government organizations.

It focuses on the user experience, information retrieval workflow, role-based interfaces, and data source management.

The platform is intended as a prototype and can be extended with production data sources, enterprise authentication, and additional AI-powered retrieval capabilities.
